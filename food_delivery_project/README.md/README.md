# 🍔 Food Delivery Analytics Dashboard

## 📌 Project Overview
This project analyzes food delivery operations using SQL and Power BI. The dataset contains customer orders, restaurant details, delivery information, and payment transactions.

The project focuses on:
- Data cleaning using SQL
- Business KPI analysis
- Operational insights
- Interactive dashboard development using Power BI

# 🧹 Data Cleaning Process
The raw datasets contained:
- NULL values
- inconsistent date formats
- missing delivery statuses
- invalid restaurant costs
- inconsistent order statuses

SQL queries were used to:
- clean missing values
- standardize formats
- validate business logic
- create cleaned tables for analysis
